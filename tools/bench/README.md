# Performance Benchmarks

pytest-benchmark tests for tracking Clifft performance over time.

## Running

```bash
just bench
```

Or directly:

```bash
uv run pytest tools/bench/ --benchmark-sort=name --benchmark-columns=Mean,StdDev,Ops
```

## Benchmarks

| File | Circuit | What it measures |
|------|---------|-----------------|
| `test_bench_qec.py` | d=3 surface code (`tests/fixtures/target_qec.stim`) | Compile and sample latency vs Stim |
| `test_bench_deep_clifford.py` | 50-qubit, 5000 random Cliffords | Pure Clifford compile/sample throughput |
| `test_bench_qv.py` | 20-qubit Quantum Volume (`fixtures/qv20_seed42.stim`) | Large statevector (peak active width 20) per-shot throughput |
| `test_bench_noncomp.py` | d=17, r=5 repetition-code memory with a hooked leak/loss layer | Noncomputational pipeline overhead and trap/continuation cost vs plain sampling |
| `test_bench_css.py` | Synthetic CSS five-check sequences, 37 and 61 data wires | Reusable logical-block plans versus ordinary dense execution |

## Fixtures

Pre-generated circuit files live in `fixtures/`:

- **`qv20_seed42.stim`** — 20-qubit Quantum Volume circuit (seed=42) in Stim-superset
  format. Peak active width 20 (2^20 = 1M complex amplitudes, 16 MB statevector).
  Useful for profiling dense active-state kernels.

- **`css_five_check_d{3,5,7,9}.stim`**: synthetic 7/19/37/61-data controls,
  generated by `tools/profile/msc_factor_sequence.py` (`Sequence(distance).circuit()`).
  Each has five T-conjugated all-Y checks, complete CSS projections, four
  depolarizing layers per check, readout noise at probability 0.001, detectors,
  and a terminal logical observable. The ideal encoded preparation isolates
  the repeated-check cost. These are not full fault-tolerant cultivation
  protocols or authors' MSC7 circuits. Even without physical faults, larger
  controls can produce nonzero check-difference detectors.

For a standalone many-shot comparison through the public sampler:

```bash
python tools/bench/measure_css_blocks.py --shots 2048 --repeats 3 --output results.json
```

Compilation is timed separately; each program is reused across shot batches.
The comparison fixes one CPU worker and scalar batching. The 7/19-data controls
check that opt-in routing retains ordinary execution. At 61 data wires the
ordinary width-31 coefficient array alone needs 32 GiB, so this script measures
only the contracted path rather than attempting that allocation. Full original
MSC d3/d5 fixtures remain separate negative controls in Python conformance tests.
