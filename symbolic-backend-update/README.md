# Clifft symbolic backend briefing

Temporary in-repository briefing page for the SymFT-style CPU backend work. The
performance values come from [`../SYMBOLIC_BACKEND_RESULTS.md`](../SYMBOLIC_BACKEND_RESULTS.md).

## Run locally

```sh
npm ci
npm run dev
```

Then open `http://localhost:3000`.

## Verify

```sh
npm run build
npm test
npm run lint
```
