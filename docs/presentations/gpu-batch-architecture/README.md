# Clifft accelerator execution presentation

Open `index.html` in a browser, or serve this directory with any static file
server. The deck is self-contained apart from the existing Clifft mark in
`docs/assets/logos/`.

Keyboard controls:

- Arrow keys, Page Up, Page Down, or Space: move between slides
- `N`: toggle speaker notes
- `F`: toggle fullscreen
- Home or End: jump to the first or last slide
